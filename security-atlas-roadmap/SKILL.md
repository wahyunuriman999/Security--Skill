# Security Atlas Roadmap — Instant Routing

870 skill di kategori `security-atlas`. Roadmap ini adalah **satu-satunya hal yang
perlu dibaca** untuk tahu skill mana yang dipakai. Tidak perlu membaca 870 deskripsi.

Cara pakai: cocokkan **sinyal tugas** di kolom kiri -> ambil skill di kolom kanan ->
`skill_view(name="<nama>")`. Kalau tugas tidak cocok satu pun, lihat §Fallback.

> Prinsip: manusia dengan banyak kemampuan tidak menghafal setiap kemampuan. Dia
> punya insting — "ini tugas X, kemampuan Y yang dipakai". Roadmap ini insting-nya.
